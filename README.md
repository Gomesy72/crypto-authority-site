# Crypto Authority Site - Trading Dashboard

## Overview
Professional crypto trading dashboard with whale watch, technical signals, and TradingView integration.

## Features
- **Real-time Prices**: Live crypto data from CoinGecko
- **Technical Signals**: RSI, MACD, Moving Averages
- **Whale Watch**: Large transaction monitoring
- **TradingView Charts**: Embedded professional charts
- **Dark Theme**: Easy on the eyes

## Setup for Hermes

### Prerequisites
- GitHub account with access to this repository
- Personal Access Token (stored in .env file)

### Files
- `index.html` - Main dashboard
- `dashboard.css` - Styling
- `dashboard.js` - Functionality
- `.env` - API keys (DO NOT COMMIT)

### GitHub Token
The token is stored in `.env` file for security. Both Joe and Hermes have access to this repository.

**Important:** 
- Never commit .env to GitHub
- Token has repo access
- Keep it secure
